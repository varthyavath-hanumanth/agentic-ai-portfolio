# Portfolio Roadmap

## Recommended order

1. Run all three projects locally and understand every function.
2. Change sample data and add at least two tests of your own.
3. Record a short demo video showing inputs, outputs, and safeguards.
4. Add a FastAPI endpoint to one project.
5. Add an LLM integration only after keeping retrieval, validation, and safety checks independent of the model.

## How to describe this honestly on a resume

**Agentic AI Portfolio Projects (Personal Projects)**
- Built a Python invoice-processing workflow that extracts labelled fields, validates totals, and routes exceptions for human review.
- Implemented a knowledge-grounded customer-support assistant with article retrieval, source attribution, and human approval.
- Developed a read-only SQLite analytics assistant that maps supported natural-language requests to allowlisted SQL templates and generates Markdown reports.

Do not describe these as professional employment experience or claim production deployment unless you actually complete those steps.
